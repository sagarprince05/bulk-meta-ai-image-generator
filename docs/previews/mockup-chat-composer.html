How the AI prompt writer works (no key in the UI)

  • The website has a small server function on Vercel. The Claude API key lives there as a secret environment variable; it is never sent to the browser and never shown anywhere.
  • Only the prompt-writing step uses it ("Let AI write prompts" and "Rewrite"). Image generation always goes through Meta AI in the user's own browser, unchanged.
  • Limits to protect your bill: max 50 prompts per request, 300 per user per day; the model is Claude Haiku, roughly ₹0.05 per 10 prompts. You can change limits or turn the feature off from Vercel without redeploying.
  • If the key is not configured, the AI toggle is simply hidden and everything else works exactly as today.
  • Desktop (.exe) version: same screen, and the AI feature calls the same Vercel function, so no key ships inside the app either.
